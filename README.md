# Hackathon Prototypes

Hackathon projects exploring career discovery and public-interest publishing. Open a project repository for its source code, technical documentation, and local setup.

## Selected projects

### [career-graph](https://github.com/oolio151/career-graph)
**HackUMBC 2026 · Python, Flask, Jinja, JavaScript, Gemini**

A career-exploration application with dataset-backed alumni comparisons and a resume workspace.

- **Engineering:** server-side model integration, dataset-grounded context, reviewable LaTeX edits, and real PDF compilation.
- **Current boundary:** the track dataset is synthetic; several pathway and activity views use illustrative fixtures.
- **Explore:** [code and setup](https://github.com/oolio151/career-graph#readme).

### [Vera](https://github.com/s-chall/vera)
**Next.js, TypeScript, Supabase, PostgreSQL**

A reporting application with journalist verification and controlled access to articles and media.

- **Engineering:** database-enforced access policies, transactional article publishing, and image metadata removal before upload.
- **Current boundary:** payment integration and engagement recording remain unfinished.
- **Explore:** [code, architecture notes, and setup](https://github.com/s-chall/vera#readme).
